# התיק הפלסטיני: חבילת העלאה לאוויר

התיקייה מוכנה להעלאה לכל אחסון סטטי, למשל GitHub Pages, Netlify או Cloudflare Pages. כל התוכן בקובץ אחד, `index.html`, כולל הפונטים. האתר לא שולח שום בקשה לשרת חיצוני עד שהגולש לוחץ על "ניגון".

| קובץ | תפקיד |
|---|---|
| `index.html` | האתר המלא: ראש דף, תיאור ותמונת שיתוף |
| `og-image.png` | התמונה שמופיעה כשמשתפים קישור בוואטסאפ, ב־X או בפייסבוק |
| `favicon.svg`, `apple-touch-icon.png` | אייקונים |
| `privacy.html`, `accessibility.html` | מדיניות פרטיות והצהרת נגישות |
| `robots.txt` | פתוח למנועי חיפוש |

**לפני ההעלאה:** אחרי שנבחר דומיין, צריך לבנות מחדש עם הכתובת שלו (`python3 build_public.py https://הדומיין/`). זה הופך את קישור תמונת השיתוף לכתובת מלאה, כי וואטסאפ ופייסבוק לא מציגים תמונה מקישור יחסי.
